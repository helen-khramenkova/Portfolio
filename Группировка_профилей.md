# Группировка профилей за 5 мин

## ✅ Причины группировки пользователей:
1. Два профиля взаимно ссылаются друг на друга.
2. Один профиль ссылается на другой с помощью подтвержденной ссылки. Подтвержденной считается ссылка, для выставления которой требуется ввести пароль другой сети.

## 🛠️ Способы объединить профили
### ❌ Для пользователей без аккаунта Яндексе
1. Перейдите на social.yandex.ru .
2. Войдите через социальную сеть.
3. Разрешите поисковой системе использовать информацию о связях между профилями.

### 🌐 Для пользователей Мой Круг
1. Откройте раздел "Я на других сайтах". (http://moikrug.ru/master/profile/sites/)
2. Добавьте необходимые профили.
3. Подтвердите сохранение редактирования.

### 💙 Для пользователей ВКонтакте
1. Откройте раздел Контакты.
2. Перейдите в раздел "Личный сайт" и укажите ссылки на профили. (http://vk.com/edit?act=contacts)
3. Далее перейдите обратно в раздел Контакты.
4. Выберете "Интеграция с другими сервисами" и укажите недостающие аккаунты. (http://vk.com/edit?act=contacts)

### ❤️ Для пользователей ya.ru
1. Откройте раздел "Дневники".
2. Добавьте необходимые данные с указанием ссылок на профили.
3. Подтвердите изменение.

### 📝 Для пользователей Livejournal
1. Откройте раздел "Способы связи" или External services.
2. Добавьте необходимые данные с указанием ссылок на профили.
3. Подтвердите изменение.

### 🧡 Для пользователей Одноклассники
- Профили могут быть сгруппированы только с помощью Яндекс.Паспорта. (https://passport.yandex.ru/profile/social)
